Rock Paper Scissors 🪨📄✂️

A simple browser-based Rock Paper Scissors game built with vanilla HTML, CSS, and JavaScript — no frameworks, no libraries.

🎮 Demo

Play against the computer: click Rock, Paper, or Scissors and see who wins!

✨ Features
Click-based gameplay (Rock / Paper / Scissors)
Random computer move generation
Live score tracking for both player and computer
Win / Lose / Draw messages with dynamic styling
Responsive circular button layout with hover effects
🛠️ Built With
HTML5
CSS3 (Flexbox)
Vanilla JavaScript (DOM manipulation, event listeners)

🚀 Getting Started

No build tools or dependencies needed.

Clone or download this repository
Open index.html in your browser

That's it — the game runs entirely client-side.
